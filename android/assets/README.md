# Generated model assets

The desktop application’s Android build buttons copy the trained
EfficientNet-Lite0 files into this directory before building:

- `efficientnet_lite0_mobile_model.tflite`
- `efficientnet_lite0_mobile_labels.txt`

Do not replace these files manually unless the model was trained with the
EleAid 48 kHz, 3-second Mobile CNN settings.
